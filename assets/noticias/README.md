# Imagens das notícias

Coloque aqui os cards ou fotos usados na página `Noticias.dc.html`.

Exemplo de uso no campo `image` de uma notícia:

```js
image: 'assets/noticias/seminario-ramires-2026.jpg'
```

Use nomes curtos, sem espaços e sem acentos, por exemplo:

- `seminario-ramires-2026.jpg`
- `defesa-ana-2026.png`
- `visita-valencia-2026.webp`
